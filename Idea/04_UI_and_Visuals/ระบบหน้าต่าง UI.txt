ระบบหน้าต่าง UI (Beyonder User Interface System)
==================================================
เวอร์ชั่นที่รองรับ: Minecraft 1.21.1 NeoForge
รูปแบบ: RPG-Style Custom HUD & Journal GUI

1. ระบบ HUD (Heads-Up Display)
----------------------------------
ส่วนที่แสดงผลบนหน้าจอขณะเล่น (Overlay)

1.1 แถบพลังวิญญาณ (Spirituality Bar)
   - ตำแหน่ง: เหนือหลอดอาหาร (Hunger Bar) หรือแสดงเป็นแถบแนวตั้งข้าง Hotbar
   - สี: สีน้ำเงินเข้มประกายดารา (Midnight Blue with Star particles)
   - กลไก: 
     * ค่อยๆ ลดลงเมื่อใช้สกิล (Burst/Drain Cost)
     * เมื่อเหลือ < 5% จะเปลี่ยนเป็นสีเทา (Spiritual Exhaustion) และหน้าจอจะสั่นเล็กน้อย
     * ตัวเลขแสดงผล (Current/Max) จะปรากฏเมื่อกด Shift หรือเปิดเมนู

1.2 มาตรวัดสติ (Sanity Meter)
   - ตำแหน่ง: มุมซ้ายบน หรือล้อมรอบ Portrait ตัวละคร
   - รูปลักษณ์: วงกลมสัญลักษณ์ "ดวงตาแห่งความรู้" (Eye of Knowledge)
   - การเปลี่ยนแปลงตามระดับความบ้าคลั่ง:
     * 100% - 90%: ดวงตาสีใส นิ่งสงบ
     * 89% - 70% (Paranoia): ดวงตาเริ่มสั่น (Shake) มีรอยร้าวสีม่วงจางๆ
     * 69% - 40% (Hallucination): รอยร้าวสีดำแผ่ขยาย ขอบหน้าจอเริ่มมืด (Vignette)
     * 39% - 1% (Madness): ดวงตาสีแดงฉาน มีเลือดไหล หน้าจอมีเอฟเฟกต์สีบิดเบี้ยว (Distortion)
     * 0% (Loss of Control): หน้าจอดับมืดสนิทก่อนตัวละครระเบิด

1.3 ช่องความสามารถลัด (Beyonder Active Skills UI)
   - ตำแหน่ง: แถบไอคอนเรียงกัน 3 ช่องทางด้านซ้ายของหน้าจอ (ระบบเดียวกับมอด tensura)
   - ความจุ: ติดตั้งได้สูงสุด 30 ความสามารถ แบ่งเป็น 10 หน้า หน้าละ 3 ช่อง
   - การขยายรายละเอียด: กด Alt ค้างไว้ ไอคอนจะขยายใหญ่ขึ้นเพื่อแสดงชื่อความสามารถด้านบน และโหมดการทำงานด้านล่าง

1.4 หน้าต่างปฏิสัมพันธ์ NPC (NPC Interaction HUD)
   - ตำแหน่ง: แสดงเมื่อนำเป้าเล็งชี้ไปที่ NPC หรือเมื่อพูดคุย
   - หลอดความรู้สึก:
     * แถบความเชื่อใจ (Trust Bar): -100 ถึง 100 ระบุสถานะ (Friendly, Neutral, Hostile, Surrender)
     * แถบความศรัทธา (Faith Bar): -50 ถึง 50 สีทอง (ปรากฏเมื่อความเชื่อใจเต็ม 100)
   - สถานะพิเศษ: กรอบชื่อลวดลายหรูหราสำหรับ "NPC พิเศษ" พร้อมสัญลักษณ์ระดับพลัง

2. ระบบเมนูหลัก (Beyonder Journal - กดปุ่ม 'G')
----------------------------------
Interface หลักสำหรับจัดการตัวละคร ใช้ Texture เป็นสมุดหนังโบราณ

2.1 หน้าประวัติ (Character Profile)
   - แสดงชื่อเส้นทาง (เช่น นักทำนาย, นักรบ)
   - แสดงลำดับปัจจุบัน (Sequence) 
   - แถบความคืบหน้าการย่อยโอสถ (Digestion Bar) - สีทองประกาย

2.2 หน้าผังทักษะ (Skill Tree & Abilities)
   - แสดงทักษะทั้งหมดที่ได้รับจากลำดับปัจจุบันและลำดับก่อนหน้า
   - ส่วนตั้งค่าสกิล Active: เลือกลงช่อง Z, X, C ใน 10 หน้า
   - ส่วนตั้งค่าสกิล Passive (ที่ไม่เพิ่มสเตตัส): สามารถกดเพื่อเปิด-ปิดได้
   - หน้าแทรกแซงเส้นทาง (สำหรับลำดับ 0+): จัดการ ปรับแต่งระยะ/ดาเมจ/Cooldown และสลับความสามารถข้ามลำดับในเส้นทางตนเองได้ พร้อมปุ่ม Save/Reset

2.3 หน้าสถานะโดยละเอียด (Statistics)
   - Max Spirituality (รวมตัวคูณประจำเส้นทาง)
   - Mental Resistance (ค่าความต้านทานสติ)
   - Spirit Body Strength (ระดับความแข็งแกร่งของกายจิต)
   - จุดยึดเหนี่ยว (Anchors) สำหรับลำดับ 3+ (แสดงจำนวนผู้ศรัทธา, การลดลงของ Sanity, และตัวคูณค่าความเสถียรที่ได้รับจากศรัทธาของ NPC)

2.4 หน้าการจัดการประทานพร (Boon Management)
   - เงื่อนไข: แสดงเฉพาะผู้วิเศษลำดับ 0 (เทพแท้จริง) หรือวันวาน (Great Old Ones)
   - ฟีเจอร์: เปิด/ปิดสิทธิ์การเป็น Node ย่อยให้เทวทูตสายพรในสังกัด และดูสถิติจำนวนพรที่ประทานไปแบ่งตามลำดับและเส้นทาง

3. ระบบการมองเห็นพิเศษ (Spiritual Vision Overlays)
----------------------------------
3.1 เนตรวิญญาณ (Spirit Vision)
   - เมื่อเปิด: หน้าจอปรับโทนสีเป็นสีฟ้าอมม่วง (Cold Filter)
   - สิ่งมีชีวิตจะมี "ออร่า" (Outline Glow) ต่างสีกัน:
     * ขาว/เขียว: ปกติ
     * แดง: มีจิตสังหาร/ศัตรู
     * ม่วงเข้ม: ผู้วิเศษ
     * ดำ: สิ่งที่แปดเปื้อน/ความจุติของเทพ
   - มองเห็น "ด้ายวิญญาณ" (Spirit Body Threads) สำหรับเส้นทางนักทำนาย

3.2 การทำสมาธิ (Cogitation View)
   - หน้าจอจะเบลอขอบ (Gaussian Blur) และเห็นเพียง "สัญลักษณ์มโนภาพ" (Unique Symbol) กลางหน้าจอ
   - มีจังหวะการเต้นของหัวใจ (Heartbeat Sound) และหลอด Spirituality จะฟื้นฟูเร็วขึ้นในมุมมองนี้

4. ข้อกำหนดทางเทคนิค (Technical Specifications for NeoForge 1.21.1)
----------------------------------
- Rendering: ใช้ `GuiGraphics` สำหรับ 2D และ `Shaders` (Post-processing) สำหรับเอฟเฟกต์บ้าคลั่ง
- Networking: ใช้ `CustomPayload` ในการ Sync ข้อมูลจาก Server ไป Client เพื่อความแม่นยำ
- Configuration: รองรับการปรับตำแหน่ง UI (Draggable UI) และการปิดบางส่วนได้ใน Config
- Keybindings:
  * [G] - เปิดสมุดผู้วิเศษ (หรือกลายร่างสัตว์ในตำนานสำหรับลำดับ 4+)
  * [V] - เปิด/ปิด เนตรวิญญาณ (และ Alt+V สำหรับเนตรพิเศษ)
  * [B] - เข้าสู่โหมดทำสมาธิ
  * [H] - การเดินทางข้ามมิติ (ลำดับ 2+)
  * [Z], [X], [C] - ใช้ความสามารถ Active ในแต่ละช่อง
  * [Alt] + Scroll/Number - สลับหน้าสกิลความสามารถ
  * [Alt] + Z/X/C - สลับโหมดของความสามารถในช่องนั้น
