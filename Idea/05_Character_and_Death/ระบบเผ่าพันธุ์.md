# ระบบเผ่าพันธุ์ (Race System) - ฉบับสมบูรณ์ (อัปเดตเงื่อนไขและภารกิจ)

ในจักรวาล *Lord of the Mysteries* การเปลี่ยนแปลงเผ่าพันธุ์ไม่ได้เป็นเพียงการเปลี่ยนรูปลักษณ์ แต่เป็นการเปลี่ยนระดับของวิญญาณและสายเลือดเพื่อให้รองรับพลังระดับสูงได้

---

## 1. เผ่าพันธุ์เริ่มต้น: มนุษย์ (Humans)
ผู้เล่นทุกคนเริ่มต้นการเดินทางในฐานะมนุษย์ ซึ่งมีความสมดุลและมีความยืดหยุ่นในการเลือกเส้นทาง (Pathway) มากที่สุด
*   **สถานะ:** ตัวคูณ 1.0 ในทุกสเตตัสพื้นฐาน
*   **บทบาท:** เป็นร่างภาชนะเริ่มต้นที่สามารถถูกขยายขีดจำกัดได้ผ่านโอสถหรือพรของเทพ

---

## 2. เงื่อนไขและวิธีการเปลี่ยนแปลงเผ่าพันธุ์ (Transformation Methods)

การก้าวข้ามความเป็นมนุษย์สามารถทำได้ผ่าน 3 วิธีหลักที่เชื่อมโยงกับระบบผู้วิเศษ:

### 2.1 การดื่มโอสถเฉพาะเส้นทาง (Mandatory Potion Advancement)
ในบางเส้นทาง ผู้วิเศษจำเป็นต้องเปลี่ยนโครงสร้างร่างกายเพื่อให้รองรับพลังในระดับกลางได้ การเปลี่ยนแปลงจะเกิดขึ้นทันทีเมื่อดื่มโอสถลำดับต่อไปนี้:
*   **ซังกวิเนียม (Sanguine):** เปลี่ยนเมื่อดื่มโอสถ **ลำดับ 7: แวมไพร์** (เส้นทางจันทรา)
*   **มิวแทนท์ (Mutant):** เปลี่ยนเมื่อดื่มโอสถ **ลำดับ 7: มนุษย์หมาป่า** หรือ **ลำดับ 6: ซอมบี้** (เส้นทางผู้ถูกล่าม)

### 2.2 การทำภารกิจเปลี่ยนสายเลือดจาก NPC (Racial NPC Quests)
ผู้เล่นสามารถพบเจอ NPC ที่เป็นตัวแทนของเผ่าพันธุ์โบราณเพื่อขอรับภารกิจ "ปลุกสายเลือด" โดยไม่ต้องเดินตามเส้นทางโอสถมาตรฐาน (แต่อาจได้รับผลข้างเคียง):
*   **ภารกิจแวมไพร์:** ทำสัญญากับ NPC ขุนนางซังกวิเนียมเพื่อรับการถ่ายเลือด
*   **ภารกิจเอลฟ์:** ค้นหา "บ่อน้ำแห่งพายุ" ในหมู่เกาะที่สาบสูญภายใต้คำชี้แนะนำของ NPC เอลฟ์
*   **ภารกิจยักษ์:** ผ่านบททดสอบความแข็งแกร่งใน "วิหารราชันยักษ์"
*   **ภารกิจมิวแทนท์:** ถูกบังคับทำพิธีสลักคำสาปโดย NPC จากกลุ่ม *Rose School of Thought*

### 2.3 การรับพรจากวันวาน (Divine Boons)
สำหรับผู้เล่นสาย "พร" (Boon System) การรับพลังจากเทพภายนอกในระดับหนึ่งจะบังคับให้ร่างกายเปลี่ยนสภาพ:
*   **มิวแทนท์:** เกิดจากพรของ **มารดาพฤกษาแห่งแรงกระหาย (Mother Tree of Desire)**

## 3. ตารางตัวคูณและข้อจำกัดประจำเผ่าพันธุ์ (Stat Multipliers & Restrictions)

| เผ่าพันธุ์ | สเตตัสเด่น | ข้อจำกัด / จุดอ่อน |
| :--- | :--- | :--- |
| **มนุษย์** | Balance (1.0) | ไม่มีพลังพิเศษในตัว |
| **ซังกวิเนียม** | AGI (1.5), APP (1.8) | **Sunlight Allergy:** ตัวไหม้เมื่อโดนแสงแดด |
| **เอลฟ์** | AGI (1.6), PER (1.6) | **Aridity:** อ่อนแรงในพื้นที่แห้งแล้ง/ทะเลทราย |
| **ยักษ์** | STR (2.0), CON (1.8) | **Colossal:** ตัวสูง 3 บล็อก ลอดช่องปกติไม่ได้, เดินช้า |
| **มังกร** | INT (1.7), PER (1.6) | **Psychic Weakness:** แพ้การโจมตีทางจิตใจแรงขึ้น 2 เท่า |
| **มิวแทนท์** | STR (1.6), CON (1.6) | **Cursed:** ถูก NPC สาย Sun/Justiciar โจมตีทันที |

## 4. กลไกเชิงระบบ (System Mechanics)

1.  **Attribute Reset:** เมื่อเปลี่ยนเผ่าพันธุ์ สเตตัสพื้นฐานจะถูกคำนวณใหม่โดยใช้ตัวคูณทันที
2.  **Permanent Change:** การเปลี่ยนแปลงนี้ "ถาวร" และไม่สามารถย้อนกลับเป็นมนุษย์ได้ (ยกเว้นเข้าสู่ระดับวันวาน)
3.  **NPC Interaction:** NPC ในมิติโลกกายภาพจะเปลี่ยนท่าทีตามเผ่าพันธุ์ของผู้เล่น (เช่น กลัวยักษ์ หรือขับไล่มิวแทนท์)
4.  **Mythical Transformation:** เมื่อถึงลำดับ 4 เผ่าพันธุ์เหล่านี้จะวิวัฒนาการเป็น **"ร่างสัตว์ในตำนาน"** ซึ่งเป็นจุดสิ้นสุดของการเปลี่ยนแปลงทางชีวภาพ
