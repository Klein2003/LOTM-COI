# ระบบเนตรวิญญาณ (Spirit Vision System)

ในจักรวาล *Lord of the Mysteries*, **เนตรวิญญาณ (Spirit Vision)** คือทักษะพื้นฐานที่สำคัญที่สุดของผู้วิเศษ เพื่อใช้มองทะลุผ่านรูปลักษณ์ภายนอกเข้าสู่แก่นแท้ของวิญญาณและโลกเร้นลับ

---

## 1. ระดับของเนตรวิญญาณ (Spirit Vision Tiers)
ประสิทธิภาพของเนตรวิญญาณจะเพิ่มขึ้นตามลำดับขั้น (Sequence) และธรรมชาติของเส้นทางที่เลือก โดยแบ่งเป็น 4 ระดับหลัก:

### **[ระดับที่ 1] ระดับเริ่มต้น (Initial - Basic Aura)**
*   **ระยะ:** 10-15 บล็อก (ภาพสั่นไหวและเบลอเป็นบางครั้ง)
*   **ความสามารถ:** มองเห็น **ออร่าพื้นฐาน (Basic Aura)** สะท้อนสถานะกายภาพ

### **[ระดับที่ 2] ระดับปานกลาง (Standard - Spiritual Sight)**
*   **ระยะ:** 30-40 บล็อก (ภาพนิมิตเสถียรและชัดเจน)
*   **ความสามารถ:** มองเห็นกายจิต (Wraith), มวลพลังวิญญาณ และประเมินความแข็งแกร่งเป้าหมาย

### **[ระดับที่ 3] ระดับเชี่ยวชาญ (Expert - Mystical Insight)**
*   **ระยะ:** 60-80 บล็อก (มองทะลุผ่านม่านพลังหรือสิ่งกีดขวางบางชนิดได้)
*   **ความสามารถ:** มองเห็น **กายอากาศ (Ether Body)** อย่างละเอียด และมองทะลุภาพมายาระดับต่ำ/กลาง

### **[ระดับที่ 4] ระดับสุดยอด (Peak - Divine Vision)**
*   **ระยะ:** ไร้ขีดจำกัด (มองเห็นแก่นแท้ของกฎเกณฑ์จักรวาล)
*   **ความสามารถ:** ตรวจสอบชื่อเส้นทางและหมายเลขลำดับได้แม่นยำ 100%, ต่อต้านการอำพรางทุกชนิด

### **[ระดับพิเศษ] ระดับพิเศษ (Special - Pathway Unique Vision)**
*   **ลักษณะ:** เป็นระดับย่อยที่ทำหน้าที่ **"ซ้อนทับ" (Overlay)** กับเนตรวิญญาณระดับหลัก (เช่น ผู้เล่นอาจมีเนตรระดับปานกลาง + ระดับพิเศษ พร้อมกันได้)
*   **ฟังก์ชัน:** มอบความสามารถในการมองเห็นรูปแบบเฉพาะตัวที่ผูกติดอยู่กับแนวคิด (Concept) ของแต่ละเส้นทางพลัง ซึ่งเส้นทางอื่นไม่สามารถลอกเลียนแบบได้ (รายละเอียดจะระบุในแต่ละเส้นทาง)

## 2. ความถนัดเฉพาะเส้นทาง (Pathway Specifics)
แต่ละเส้นทางมี "เพดานสูงสุด" และการเข้าถึง "ระดับพิเศษ" ที่แตกต่างกัน (รายละเอียดความสามารถพิเศษจะถูกอธิบายในไฟล์ของแต่ละเส้นทาง):

| เส้นทาง (Pathway) | เพดานสูงสุด | เนตรวิญญาณระดับพิเศษ |
| :--- | :---: | :---: |
| Fool, Wheel of Fortune, Hermit, White Tower | **ระดับสุดยอด** | มี |
| Visionary, Door, Sublunary Eye | **ระดับสุดยอด** | มี |
| Eternal Edict, Eternal Aeon, Everlasting, Chaos Mist | **ระดับสุดยอด** | มี |
| Death, Darkness, Chained, Mother, Moon, Sun, Abyss | ระดับเชี่ยวชาญ | มี |
| Second Law, Chaos Primogenitor, Patriarch | ระดับเชี่ยวชาญ | มี |
| Error | ระดับเชี่ยวชาญ | มี |
| Paragon, Demoness, Justiciar, Black Emperor | ระดับปานกลาง | มี |
| Tail-Devourer, Condenser | ระดับปานกลาง | มี |
| Twilight Giant, Tyrant, Red Priest | ระดับปานกลาง | ไม่มี |

## 3. กลไกและข้อจำกัดในเกม

### **การเปิดใช้งาน (Activation)**
*   **การควบคุม:** กดคีย์ลัดเพื่อเปิด/ปิด "สภาวะเนตรวิญญาณ"
*   **การสลับโหมด:** สำหรับเส้นทางที่มี **เนตรวิญญาณระดับพิเศษ** ผู้เล่นสามารถเลือกเปิด-ปิดเฉพาะส่วนเสริมพิเศษแยกจากเนตรวิญญาณหลักได้ผ่านหน้าต่างตั้งค่าหรือคีย์ลัดเฉพาะ
*   **ข้อแลกเปลี่ยน:** จะค่อยๆ ลดค่าพลังวิญญาณ (Spirituality) ลงต่อเนื่อง โดยระดับที่สูงขึ้นหรือการเปิดระดับพิเศษจะใช้พลังงานมากขึ้น

### **อุปสรรคและผลสะท้อนกลับ (Backlash)**
1.  **การอำพราง:** หากระดับเนตรต่ำกว่าระดับการปกปิดของเป้าหมาย ภาพที่เห็นจะมืดบอดหรือเบลอ
2.  **"อย่าจ้องมองพระเจ้า":** การใช้เนตรวิญญาณจ้องมองตัวตนระดับเทพ (Sequence 0) หรือเทพภายนอก (GOO) โดยไม่มีการป้องกัน จะส่งผลให้ตาบอดถาวร, สูญเสีย Sanity ทั้งหมด และเสียชีวิตทันที
