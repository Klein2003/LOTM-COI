# ระบบค่าสเตตัสและเพศกำเนิด (Core Stats & Gender System)

ในจักรวาล *Lord of the Mysteries* ความสามารถของผู้วิเศษไม่ได้ถูกกำหนดเพียงแค่ลำดับพลัง แต่ยังรวมถึงรากฐานทางสรีระและจิตใจที่สะท้อนผ่านค่าสเตตัสพื้นฐานและค่าสเตตัสพิเศษ ซึ่งจะส่งผลโดยตรงต่อประสิทธิภาพของพลังวิเศษในแต่ละเส้นทาง

- ค่าเกณฑ์ (จุดที่กำหนด) และค่าคงที่ต่างๆ ของระบบนี้รวมไว้ที่ไฟล์ *ค่าเกณฑ์และค่าคงที่ของระบบค่าสเตตัส.md*
- ค่าสเตตัสของแต่ละเส้นทางในแต่ละลำดับดูได้ที่โฟลเดอร์ *07_Pathway_Stats*

---

## 1. ค่าสเตตัสต่างๆ

### 1.1 ค่าสเตตัสพื้นฐาน
ค่าสเตตัสพื้นฐานคือค่าสเตตัสที่ทุกสิ่งมีชีวิตมีเหมือนกัน (ค่าสเตตัสพื้นฐานจะเริ่มต้นที่ 10 แต้ม)
*   **พละกำลัง (Strength - STR):**
    * เพิ่มความเสียหาย Melee และระยะ Knockback เมื่อโจมตีปกติ
    * ส่งผลต่อความรุนแรงของทักษะสายกายภาพ (ในกรณีที่มีการนำค่า STR ไปคำนวณความเสียหายเท่านั้น)
    * เพิ่มความสูงของการกระโดด
    * เพิ่มความเร็วในการขุด (Mining Speed) ชดเชยสถานะ Mining Fatigue
*   **ความทนทาน (Constitution - CON):**
    * เพิ่ม Max HP และอัตราการฟื้นฟูพลังชีวิตตามธรรมชาติ
    * ส่งผลให้ได้รับ "ค่าเกราะกายภาพ" โดยตรง
    * ช่วยลดระยะจากการโดน Knockback
    * มีผลต่อ Spiritual Armor (ร่วมกับ INT และ INS)
    * ช่วยลดอัตราดาเมจที่สะท้อนจากกายอากาศเข้าสู่กายหยาบ เมื่อเกิดภาวะวิญญาณบาดเจ็บ (Spiritual-to-Physical Feedback)
    * เพิ่มความต้านทานต่อสถานะผิดปกติทางกายภาพ (เช่น Poison, Wither, Disease) ส่วนการต้านทานสถานะผิดปกติทุกชนิดเป็นหน้าที่ของ FOR
*   **ความคล่องตัว (Agility - AGI):**
    * เพิ่มความเร็วในการเคลื่อนที่
    * เพิ่มความเร็วโจมตี (Attack Speed) และลดคูลดาวน์การง้างอาวุธ
    * ลดความเสียหายจากการตกจากที่สูง
    * มีผลต่อ Normal Evasion (ร่วมกับ PER) ซึ่งทำให้มีโอกาสไม่ได้รับความเสียหายจากการโจมตีกายภาพและวิญญาณ
*   **สติปัญญา (Intelligence - INT):**
    * ปลดล็อก "การป้องกันทางจิต" 4 ระดับ (ต้น, กลาง, สูง, สมบูรณ์) ตามเกณฑ์ค่า INT ซึ่งป้องกันไม่ให้ค่าสติลดลงต่ำกว่าระดับที่กำหนด และป้องกันการโจมตีทางจิตในระดับที่กำหนดได้ (อ้างอิง *ระบบสติสัมปชัญญะและความคุ้มคลั่ง.md*)
    * ลดต้นทุนพลังวิญญาณในการกดใช้ทักษะ (Burst Cost) และการรักษาสถานะทักษะ (Drain Cost)
    * มีผลต่อ Spiritual Armor (ร่วมกับ INS และ CON)
    * ส่งผลต่อความรุนแรงของทักษะสายจิตใจหรือวิญญาณ (ในกรณีที่มีการนำค่า INT ไปคำนวณความเสียหายเท่านั้น)
    * ใช้คำนวณความเสียหายธาตุ (ไฟ, น้ำ, ลม, สายฟ้า, แสง ฯลฯ) โดย **ความเสียหายธาตุ = INT × ค่าคงที่ของธาตุนั้นๆ** (แต่ละธาตุมีค่าคงที่เป็นของตัวเอง)
*   **ประสาทสัมผัส (Perception - PER):**
    * ช่วยให้สัมผัสถึงแรงดึงดูดของตะกอนพลัง ทำให้รู้ตัวเมื่อมีผู้วิเศษหรือสมบัติระดับสูงอยู่ใกล้ๆผู้ใช้ โดยที่มันจะแสดงออกมาในลักษณะของแสงสีต่างตามระดับของเป้าหมายเมื่อเทียบกับผู้ใช้ จากสีเขียว (ปลอดภัย) ถึง สีแดง (อันตราย) (ความสามารถนี้จะมีผลก็ต่อเมื่อค่า PER สูงเกินจุดที่กำหนด)
    * เพิ่มรัศมีการมองเห็นของเนตรวิญญาณ (Spirit Vision)
    * ส่งผลต่อระยะการตรวจจับของ Danger Intuition (เช่น ขอบจอแดงหรือเสียงหัวใจเต้นเมื่อมีม็อบมุ่งร้าย) หรือความสามารถที่มีการนำค่า PER ไปคำนวณ
    * มีผลต่อ Normal Evasion (ร่วมกับ AGI)

### 1.2 ค่าสเตตัสพิเศษ
เป็นค่าสเตตัสที่มีเงื่อนไขในการได้รับ
*   **เสน่ห์ (Charm - CHA)** จะต้องมีระดับตัวตน (ความแข็งแกร่งของกายจิต) ตั้งแต่ Tier 1 ขึ้นไป (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * **ค่า CHA จะเพิ่มได้จากการมีปฏิสัมพันธ์ที่ดีกับ NPC ต่างๆ เท่านั้น** โดยต้องสร้างความสัมพันธ์กับ NPC นั้นให้ถึงระดับที่กำหนดจึงจะได้รับแต้ม (ไม่ได้รับจากการแบ่งแต้มของเส้นทาง)
    * ลดราคาไอเทมจาก NPC พ่อค้า
    * ลดโอกาสที่ม็อบสิ่งมีชีวิตทั่วไปจะโจมตีผู้ใช้ก่อน
    * มีโอกาสที่จะได้รับรางวัลตอบแทนจากภารกิจเพิ่มเติม (ความสามารถนี้จะมีผลก็ต่อเมื่อค่า CHA สูงเกินจุดที่กำหนด)
*   **โชค (Luck - LUK)** จะต้องมีระดับตัวตน (ความแข็งแกร่งของกายจิต) ตั้งแต่ Tier 1 ขึ้นไป (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * ค่า LUK จะมีค่าสูงสุดอยู่ที่ +100 และต่ำสุดอยู่ที่ -100
    * เมื่อค่า LUK สูงเกินจุดที่กำหนด จะทำให้ผู้ใช้ได้ของดีๆเมื่อทำการสุ่มหรือความสามารถที่มีโอกาสทำงานก็จะเพิ่มโอกาสทำงานได้มากขึ้น
    * เมื่อค่า LUK ต่ำเกินจุดที่กำหนด จะทำให้ผู้ใช้ได้ของไม่ดีเมื่อทำการสุ่มหรือความสามารถที่มีโอกาสทำงานก็จะลดโอกาสทำงานมากขึ้น
    * **ค่า LUK จะเพิ่มลดได้จากความสามารถบางประเภทเท่านั้น**
*   **ความงาม (Beauty - BEA):** จะต้องเป็นเพศหญิงหรือสองเพศเท่านั้น (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มความสัมพันธ์กับ NPC เพศตรงข้ามได้ง่ายขึ้น
    * มีโอกาสที่ NPC หรือม็อบจะไม่โจมตีผู้ใช้เมื่อผู้ใช้โจมตีก่อน (ความสามารถนี้จะมีผลก็ต่อเมื่อค่า BEA สูงเกินจุดที่กำหนด)
    * มีโอกาสที่ NPC หรือม็อบจะกลายเป็นทาสของผู้ใช้ ทาสมีทั้งแบบชั่วคราวและถาวร (ความสามารถนี้จะมีผลก็ต่อเมื่อค่า BEA สูงเกินจุดที่กำหนด)
        * **เงื่อนไขการใช้:** ต้องพูดคุยหรือคลิกขวาที่เป้าหมายในระยะประชิดเท่านั้น ระยะจะเพิ่มขึ้นตามระดับตัวตน สูงสุดคือ 100 block
        * **การคำนวณ:** เทียบค่า BEA ของผู้ใช้กับ (INT + FOR) ของเป้าหมาย (ถ้าเป้าหมายไม่มี FOR ให้ใช้ INT อย่างเดียว และตัวหารต่ำสุดเป็น 1) โดยไม่สนใจระดับของเป้าหมาย
        * ถ้า BEA ÷ (INT + FOR) มากกว่า 10 เท่า เป้าหมายจะเป็นทาสชั่วคราว และถ้ามากกว่า 50 เท่า จะเป็นทาสถาวร
*   **ความหล่อ (Handsome - HAN):** จะต้องเป็นเพศชายหรือสองเพศเท่านั้น (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มความสัมพันธ์กับ NPC เพศตรงข้ามได้ง่ายขึ้น
    * มีโอกาสที่ NPC หรือม็อบจะไม่โจมตีผู้ใช้เมื่อผู้ใช้โจมตีก่อน (ความสามารถนี้จะมีผลก็ต่อเมื่อค่า HAN สูงเกินจุดที่กำหนด)
    * สามารถชวน NPC มาเป็นพวกได้โดยที่ไม่ต้องให้มีค่าความสัมพันธ์ถึงเกณฑ์ และพวกพ้องของผู้ใช้จะได้รับโบนัสค่าสเตตัสตั้งแต่ x1.1 ถึง x2 ตามค่า HAN ของผู้ใช้ และโบนัสเพิ่มประสิทธิภาพของความสามารถตั้งแต่ x1.1 ถึง x3 ตามค่า HAN ของผู้ใช้ (ความสามารถนี้จะมีผลก็ต่อเมื่อค่า HAN สูงเกินจุดที่กำหนด)
*   **บารมี (Presence - PRE):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มค่าความเชื่อใจ (Trust) ของ NPC กับผู้ใช้ได้ง่ายขึ้น
    * เพิ่มประสิทธิภาพของจุดยึดเหนี่ยว (Anchors) ทำให้การเปลี่ยน NPC เป็นผู้ศรัทธาทำได้ง่ายขึ้น
    * มีโอกาสที่สิ่งมีชีวิตจะไม่โจมตีผู้ใช้ (ความสามารถนี้จะมีผลก็ต่อเมื่อค่า PRE สูงเกินจุดที่กำหนด)
*   **อำนาจข่มขู่ (Dominance - DOM):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * ส่งผลต่อความรุนแรงของบางความสามารถที่ใช้ค่า DOM ไปคำนวณ
    * มีโอกาสที่จะสามารถบังคับให้ NPC มาเป็นพวกเดียวกับผู้ใช้ได้ แต่ค่าสเตตัสของเป้าหมายที่โดนบังคับมาจะลดลงตั้งแต่ -10% ถึง -50% ตามค่า DOM ของผู้ใช้ และพวกพ้องที่โดนบังคับมาจะมีระยะเวลาในการอยู่ในทีมตั้งแต่ 1 วันในเกม ถึง 100 วันในเกม ตามค่า DOM ของผู้ใช้ (ความสามารถนี้จะมีผลก็ต่อเมื่อค่า DOM สูงเกินจุดที่กำหนด)
        * **การคำนวณ:** โอกาสบังคับสำเร็จคำนวณจากค่า DOM ของผู้ใช้เทียบกับ (INT + FOR) ของเป้าหมาย (ถ้าเป้าหมายไม่มี FOR ให้ใช้ INT อย่างเดียว และตัวหารต่ำสุดเป็น 1) โดยไม่สนใจระดับของเป้าหมาย เช่นเดียวกับ BEA
*   **ปัญญาญาณ (Insight - INS):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มประสิทธิภาพของทักษะสาย การทำนาย (Divination), การพยากรณ์ (Prophecy) และ การมองเห็นอนาคต (Foresight)
    * ส่งผลต่อ Spiritual Armor (ร่วมกับ INT และ CON)
    * เมื่อค่า INS สูงเกินจุดที่กำหนด: ผู้ใช้จะสามารถ เห็นผ่านภาพลวงตา (Illusion Piercing) และ ตรวจจับศัตรูที่ใช้การล่องหนหรือซ่อนตัว ได้ (ตอบโต้สกิล Concealment)
    * ส่งผลต่อความรุนแรงของทักษะที่มีการนำค่า INS ไปคำนวณ
*   **ความทนทุกข์ (Fortitude - FOR):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มค่า ต้านทานสถานะผิดปกติ (Status Resistance) ทุกชนิด เช่น สลบ, หลับ, หลอน, ถูกสาป, ถูกสะกดจิต, ถูกบังคับ ฯลฯ
    * ลดระยะเวลาของ Debuff ที่ผู้ใช้ได้รับ
    * เมื่อค่า FOR สูงเกินจุดที่กำหนด: ผู้ใช้จะมีโอกาสที่จะ ภูมิคุ้มกันสมบูรณ์ (Full Immunity) ต่อ Status Effect ที่มีระดับต่ำกว่าจุดที่กำหนด
    * มีผลต่อ การป้องกันทางจิต (ร่วมกับ INT)
*   **ศรัทธา (Faith - FAI):** เงื่อนไข: จะได้รับเมื่อถึงครึ่งเทพ (ลำดับ 4 ขึ้นไป) เท่านั้น (เริ่มต้นที่ 0 แต้ม) และค่านี้จะ เพิ่มลดได้ตามจำนวนและระดับของผู้ศรัทธา (Believers) ที่ผู้ใช้ครอบครอง
    * เพิ่มประสิทธิภาพของ จุดยึดเหนี่ยว (Anchors) ทำให้ต้านทานการสูญเสียตัวตนได้ดีขึ้น
    * เมื่อค่า FAI สูงเกินจุดที่กำหนด: ผู้ใช้จะสามารถ ประทานพร (Bestow Blessings) ให้ผู้ศรัทธาของตนได้ ผู้ศรัทธาจะได้รับโบนัสค่าสเตตัสตั้งแต่ x1.05 ถึง x1.5 ตามค่า FAI ของผู้ใช้
    * ค่า FAI จะเพิ่มลดได้จากจำนวนและระดับของผู้ศรัทธาเท่านั้น (คล้ายกับค่า LUK ที่เพิ่มลดได้จากความสามารถบางประเภท)
*   **เล่ห์เหลี่ยม (Cunning - CUN):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มประสิทธิภาพของทักษะสาย Stealth, Disguise, Theft, Deception
    * ลดระยะตรวจจับของม็อบระดับ Boss/Named NPC (ม็อบที่ปกติมองผ่านการซ่อนตัวได้)

## 2. ค่าสเตตัส

### 2.1 ค่าสเตตัสที่ได้ในแต่ละลำดับ
ค่าสเตตัสที่ได้รับในแต่ละลำดับนั้นเกิดจาก ตะกอนพลัง, พร, เอกลักษณ์, แก่นแท้ต้นกำเนิด เท่านั้น ส่วน **พิธีกรรมเลื่อนลำดับ** จะเพิ่มค่าสเตตัสให้ผู้ที่เลื่อนลำดับตามปกติมีค่าสเตตัสรวมตรงกับผลรวมปกติในตารางข้อ 2.2

*   **พร:** ได้รับครึ่งหนึ่งของแต้มที่ลำดับนั้นเพิ่มขึ้นจากลำดับก่อนหน้าในตารางข้อ 2.2 คือ (ผลรวมปกติของลำดับนั้น − ผลรวมปกติของลำดับก่อนหน้า) ÷ 2 พรเป็นแหล่งแต้มเสริม และการเลื่อนลำดับด้วยพรจะไม่ได้รับแต้มจากพิธีกรรมเลื่อนลำดับ
*   **พิธีกรรมเลื่อนลำดับ:** ได้รับแต้มก็ต่อเมื่อเลื่อนลำดับสำเร็จแล้วเท่านั้น และเป็นค่าคงที่ตามตาราง (ไม่เติมให้ครบผลรวมปกติ ส่วนที่เกินจะถูกจำกัดด้วยเพดานในข้อ 2.2)
    *   **แต้มพิธีกรรมของลำดับเดียวกันได้ครั้งเดียว:** เช่น เทพที่ทำพิธีกรรมลำดับ 0 ของเส้นทางที่ 2 ยังต้องทำพิธีกรรมเพื่อเป็นเทพของเส้นทางนั้น แต่จะไม่ได้แต้ม 32,000 เพิ่มอีก (หลักเดียวกับการดื่มซ้ำในข้อ 3.1)
*   **เอกลักษณ์:** 30,000 แต้ม (แปรผันตามเปอร์เซ็นต์การควบคุม)
*   **แก่นแท้ต้นกำเนิด:** ขึ้นอยู่กับจำนวนเส้นทางในแก่นแท้ต้นกำเนิดนั้น (แปรผันตามเปอร์เซ็นต์การควบคุม) คำนวณจาก 600,000 − 54,000 × (จำนวนเส้นทาง − 1)
    *   มี 1 เส้นทาง: 600,000 แต้ม
    *   มี 2 เส้นทาง: 546,000 แต้ม
    *   มี 3 เส้นทาง: 492,000 แต้ม
    *   มี 4 เส้นทาง: 438,000 แต้ม
    *   มี 5 เส้นทาง: 384,000 แต้ม
    *   *54,000 คือแต้มของเส้นทางใกล้เคียง 1 เส้นทาง = ตะกอนพลังลำดับ 1 จำนวน 3 ก้อน (24,000) + เอกลักษณ์ (30,000) ทำให้วันวานทุกกลุ่มได้ค่าสเตตัสรวมเท่ากัน*

- *ค่าสเตตัสที่ได้จากเอกลักษณ์และแก่นแท้ต้นกำเนิดจะไม่ถูกปรับแก้ แต่จะแปรผันตามเปอร์เซ็นต์การควบคุม ยิ่งควบคุมได้มากก็ยิ่งได้ค่าสเตตัสมาก (สูตรการแปรผันดูที่ไฟล์ "ค่าเกณฑ์และค่าคงที่ของระบบค่าสเตตัส.md") ส่วนผลอื่นๆ ของเปอร์เซ็นต์การควบคุมจะอยู่ในระบบเอกลักษณ์และระบบแก่นแท้ต้นกำเนิด (กำหนดภายหลัง)*
- *ลำดับ 0 ไม่มีตะกอนพลังลำดับ 0 เพราะ "โอสถลำดับ 0" คือ **ตะกอนพลังลำดับ 1 จำนวน 3 ก้อน + เอกลักษณ์** แต้มของลำดับ 0 จึงมาจาก ตะกอนพลังลำดับ 1 ทั้ง 3 ก้อน + เอกลักษณ์ + พิธีกรรมเลื่อนลำดับ 32,000 แต้ม*
- *ตะกอนพลังของเส้นทางนอกมาตรฐานทั้งหมดอยู่ที่เทพภายนอกของเส้นทางนั้น ในโลกจึงหาตะกอนพลังหรือวัตถุดิบหลักมาปรุงโอสถไม่ได้ แต่สามารถได้ตะกอนพลังมาด้วยวิธีต่างๆ (ยกเว้นการเสกขึ้นมา) เช่น สร้างความสัมพันธ์กับเทพภายนอกจนถึงระดับหนึ่ง, ทำให้เทพภายนอกบาดเจ็บจนดรอปตะกอนพลังบางส่วน, สังหารเทพภายนอกเพื่อให้ดรอปตะกอนพลังทั้งหมด หรือใช้ความสามารถประเภทขโมยเพื่อขโมยตะกอนพลังออกมา*
- *ตัวอย่างการเลื่อนลำดับตามปกติ: ลำดับ 2 (10,000) + ตะกอนพลังลำดับ 1 (8,000) + พิธีกรรม (4,000) = **ลำดับ 1 (22,000)** → + ตะกอนพลังลำดับ 1 ก้อนที่ 2 (8,000) = **ลำดับ 1 พิเศษ (30,000)** → + ตะกอนพลังลำดับ 1 ก้อนที่ 3 (8,000) + เอกลักษณ์ 100% (30,000) + พิธีกรรม (32,000) = **ลำดับ 0 (100,000)***

*   **สาย B:** Door, Tyrant, White Tower, Error, Justiciar, Black Emperor, Paragon, Twilight Giant, Wheel of Fortune, Abyss, Eternal Edict, Everlasting, Chaos Mist, Tail-Devourer, Second Law (15 เส้นทาง)

    - *ลำดับ 1 พิเศษ: มีตะกอนพลังลำดับ 1 ในร่าง 2 ก้อนขึ้นไป หรือ ควบคุมเอกลักษณ์ได้ **>= 80%** หรือทั้งสองอย่าง*
    - *ลำดับ 0 พิเศษ: ควบคุมแก่นแท้ต้นกำเนิดได้ **>= 80%** แต่ยังครอบครองเอกลักษณ์และตะกอนพลังของเส้นทางใกล้เคียงไม่ครบ*
- **หมายเหตุ 3:** *ตารางค่าสเตตัสนี้เป็นค่าสเตตัสดิบที่ยังไม่ได้รวมกับโบนัสที่เพิ่มค่าสเตตัสต่างๆ*
- **หมายเหตุ 4:** *เพดานสเตตัสรวมมีไว้เพื่อป้องกันไม่ให้ค่าสเตตัสรวมของลำดับที่ต่ำกว่าสูงเกินผลรวมปกติของลำดับที่สูงกว่า (ใช้ได้กับทุกลำดับ)*
    - *ลำดับ 1 พิเศษ: ผลรวมปกติ 30,000 = ลำดับ 1 (22,000) + ตะกอนพลังลำดับ 1 ก้อนที่ 2 (8,000) / เพดาน 68,000 = ลำดับ 1 + ตะกอนพลังลำดับ 1 อีก 2 ก้อน (16,000) + เอกลักษณ์ 100% (30,000)*
    - *ลำดับ 0: เพดาน 316,000 รองรับเทพหลายเส้นทาง (สูงสุด 5 เส้นทาง) = ลำดับ 0 (100,000) + เส้นทางใกล้เคียง 4 เส้นทาง × 54,000 (พิธีกรรมลำดับ 0 ได้แต้มครั้งเดียว)*
    - *ลำดับ 0 พิเศษ: ผลรวมปกติ 407,200 = ลำดับ 0 (100,000) + แก่นแท้ต้นกำเนิด 5 เส้นทางที่ควบคุมได้ 80% (307,200) ซึ่งเป็นค่าต่ำสุดของลำดับนี้ / เพดาน 700,000 = ลำดับ 0 + เส้นทางใกล้เคียงทั้งหมด + แก่นแท้ต้นกำเนิด 100% ซึ่งได้ 700,000 เท่ากันทุกกลุ่ม (เช่น กลุ่ม 1 เส้นทาง: 100,000 + 600,000 / กลุ่ม 5 เส้นทาง: 100,000 + 216,000 + 384,000)*
    - *วันวาน: 700,000 + พิธีกรรม 300,000 = 1,000,000 เท่ากันทุกกลุ่ม ไม่ว่าจะเป็นเทพเส้นทางเดียวหรือหลายเส้นทางมาก่อน*
- **หมายเหตุ 5:** *โบนัสค่าสเตตัสทั้งหมด (ข้อ 3.2, 3.3, โบนัสพวกพ้องจาก HAN และพรจาก FAI) จะนำมาคิดหลังจากเช็คเพดานสเตตัสแล้ว*

## 3. การเพิ่มลดของค่าสเตตัส

### 3.1 จากการดื่มโอสถ
การดื่มโอสถแต่ละลำดับจะช่วยเพิ่มค่าสเตตัสแบบคงที่ตามในข้อ 2.1 แต่หากดื่มโอสถในลำดับเดียวกับที่เคยดื่มไปแล้วค่าสเตตัสที่ได้รับก็จะลดลงตามนี้
*   **ซ้ำอันแรก:** ได้รับค่าสเตตัสลดลง **-75%**
*   **ซ้ำอันที่สอง:** ได้รับค่าสเตตัสลดลง **-95%**
*   **ซ้ำอันที่สามขึ้นไป:** ได้รับค่าสเตตัสลดลง **-100%** (ไม่ได้รับค่าสเตตัสเพิ่มอีกต่อไป)
*   **ข้อยกเว้น:** ตะกอนพลังลำดับ 1, พรลำดับ 1, เอกลักษณ์ และแก่นแท้ต้นกำเนิด จะไม่ได้รับผลกระทบจากการลดทอนนี้

### 3.2 โบนัสเพิ่มค่าสเตตัสจากระดับตัวตน
ในแต่ละระดับตัวตนจะได้รับโบนัสค่าสเตตัสตามนี้ (คำนวณหลังจากเช็คเพดานสเตตัสแล้ว)
*  **Tier 0 (ลำดับ 10):** ค่าสเตตัสทุกอย่าง x1 ยกเว้น LUK, FAI
*  **Tier 1 (ลำดับ 9–8):** ค่าสเตตัสทุกอย่าง x1.2 ยกเว้น LUK, FAI (ลำดับ 7 สาย B ก็อยู่ใน Tier นี้ด้วย เป็นกรณีพิเศษ)
*  **Tier 2 (ลำดับ 7–5):** ค่าสเตตัสทุกอย่าง x1.5 ยกเว้น LUK, FAI (ลำดับ 7 สาย A และลำดับ 6 ทั้งสาย A และ B)
*  **Tier 3 (ลำดับ 4–3):** ค่าสเตตัสทุกอย่าง x2 ยกเว้น LUK, FAI
*  **Tier 4 (ลำดับ 2–1):** ค่าสเตตัสทุกอย่าง x4 ยกเว้น LUK, FAI (ลำดับ 1 พิเศษก็อยู่ใน Tier นี้ด้วย)
*  **Tier 5 (ลำดับ 0):** ค่าสเตตัสทุกอย่าง x6 ยกเว้น LUK, FAI (ลำดับ 0 พิเศษก็อยู่ใน Tier นี้ด้วย)
*  **Tier 6 (วันวาน):** ค่าสเตตัสทุกอย่าง x10 ยกเว้น LUK, FAI

### 3.3 ไอเทมและพิธีกรรมต่างๆ
ไอเทมและพิธีกรรมต่างๆ สามารถช่วยเพิ่มหรือลดค่าสเตตัสได้ แต่ผลของพวกมันจะอยู่เพียงชั่วคราว

### 3.4 การย่อยโอสถ
*   เมื่อเพิ่งดื่มโอสถ (สถานะการย่อย 0%) จะได้รับค่าสเตตัสจากตะกอนพลังของลำดับนั้นเพียง **50%** และอีก 50% ที่เหลือจะค่อยๆ ปลดล็อกตามเปอร์เซ็นต์การย่อยจนครบ 100% เมื่อย่อยสำเร็จ
*   แต้มจากพิธีกรรมเลื่อนลำดับจะได้รับครบทันทีเมื่อเลื่อนลำดับสำเร็จ (ไม่ขึ้นกับการย่อย)

### 3.5 พร (Boons)
*   แต้มที่ได้จากพรเป็นไปตามข้อ 2.1 (ครึ่งหนึ่งของแต้มที่ลำดับนั้นเพิ่มขึ้น และไม่ได้รับแต้มจากพิธีกรรมเลื่อนลำดับ)
*   ค่าสเตตัสที่ได้จากพรจะสูญเสียไปทั้งหมดหากเทพเจ้าดึงพรกลับคืน
*   พรสายแรกจะไม่ได้รับผลของการลดทอนจากการได้รับซ้ำ (ไม่นับเป็นซ้ำอันแรก) แต่การลดทอนตามข้อ 3.1 จะเริ่มทำงานเมื่อรับพรใน **สายที่ 2 เป็นต้นไป**

### 3.6 การร่วงหล่น (Sequence Drop)
*   หากสูญเสียตะกอนพลัง ค่าสเตตัสทั้งหมดที่ได้จากตะกอนพลังนั้นจะถูกหักออกทันที
*   แต้มที่หักออกจะเป็นค่าเดียวกับที่เคยแบ่งให้แต่ละค่าสเตตัสตอนได้รับ (ตามกติกาข้อ 5)

## 5. ความถนัดของเส้นทางทั้ง 32 เส้นทาง
ในแต่ละเส้นทางค่าสเตตัสที่เพิ่มขึ้นจะถูกแบ่งออกเป็น 3 ส่วนได้แก่:
*   **สเตตัสหลัก (Primary):** ได้รับส่วนแบ่ง **60%** ของค่าสเตตัสรวม
*   **สเตตัสรอง (Secondary):** ได้รับส่วนแบ่ง **25%** ของค่าสเตตัสรวม
*   **สเตตัสอื่นๆ (Tertiary):** ได้รับส่วนแบ่ง **15%** ของค่าสเตตัสรวม

**การแบ่งแต้มภายในแต่ละส่วน**
*   ค่าสเตตัสในแต่ละส่วนจะเรียงตามความสำคัญจากมากไปน้อย ตัวเลข % ในวงเล็บคือความสำคัญของค่านั้นภายในส่วนของมัน (รวมกันได้ 100% ในแต่ละส่วน) ยิ่งค่ามากก็จะได้รับส่วนแบ่งของส่วนนั้นมากขึ้น
*   **แต้มเป็นจำนวนเต็มเสมอ:** ถ้าแต้มรวมของก้อนนั้นเป็นทศนิยม (เช่น จากการดื่มซ้ำ หรือเปอร์เซ็นต์การควบคุม) ให้ปัดลงเป็นจำนวนเต็มก่อน จากนั้นในแต่ละขั้นให้คำนวณแต่ละค่าแล้วปัดเศษลง แล้วแจกแต้มที่เหลือทีละ 1 แต้มจากซ้ายไปขวา (ค่าที่อยู่ก่อนได้รับแต้มก่อนเสมอ)
    1. แบ่งแต้มของก้อนนั้นออกเป็น 3 ส่วน (หลัก → รอง → อื่นๆ)
    2. แบ่งแต้มของแต่ละส่วนให้ค่าสเตตัสในส่วนนั้น
*   **ตัวอย่าง เดอะฟูล ลำดับ 8 (30 แต้ม):**
    *   ขั้นที่ 1: หลัก 60% = 18, รอง 25% = 7.5 → 7, อื่นๆ 15% = 4.5 → 4 รวม 29 เหลือ 1 แต้มให้ส่วนหลัก → **หลัก 19 / รอง 7 / อื่นๆ 4**
    *   ขั้นที่ 2 ส่วนหลัก 19: AGI 55% = 10.45 → 10, INS 45% = 8.55 → 8 เหลือ 1 ให้ AGI → **AGI 11, INS 8**
    *   ขั้นที่ 2 ส่วนรอง 7: PER 55% = 3.85 → 3, CUN 45% = 3.15 → 3 เหลือ 1 ให้ PER → **PER 4, CUN 3**
    *   ขั้นที่ 2 ส่วนอื่นๆ 4: INT 55% = 2.2 → 2, STR/CON/HAN/BEA 15% = 0.6 → 0 เหลือ 2 ให้ INT และ STR → **INT 3, STR 1, CON 0, HAN/BEA 0**
    *   รวมทั้งหมด 11 + 8 + 4 + 3 + 3 + 1 = 30 แต้ม

**การเปลี่ยนเส้นทางและผู้วิเศษหลายเส้นทาง**
*   แต้มแต่ละก้อนจะแบ่งตามตาราง 5.2 ของ **เส้นทางที่เป็นแหล่งที่มาของแต้มนั้น** (โอสถ, พร, เอกลักษณ์ หรือแก่นแท้ต้นกำเนิด) เท่านั้น แต้มที่ได้มาแล้วจะไม่ถูกแบ่งใหม่
*   ตัวอย่าง: นาย A เป็นผู้วิเศษลำดับ 5 เส้นทาง Fool สัดส่วนค่าสเตตัสโดยรวมยังเป็นของ Fool แต่เมื่อขึ้นลำดับ 4 โดยเปลี่ยนเป็นเส้นทาง Door แต้มของโอสถลำดับ 4 จะแบ่งตามตารางของ Door สัดส่วนค่าสเตตัสโดยรวมจึงเปลี่ยนไปจากเดิม
*   ผู้วิเศษหลายเส้นทางจะมีสัดส่วนค่าสเตตัสโดยรวมเป็นผลรวมจากหลายตาราง จึงอาจไม่ตรงกับตาราง 5.2 ของเส้นทางใดเส้นทางหนึ่ง
*   **แก่นแท้ต้นกำเนิด:** แต้มจากแก่นแท้ต้นกำเนิดจะแบ่งเป็นก้อนเท่าๆ กันให้ทุกเส้นทางในกลุ่มของแก่นแท้นั้น แล้วแต่ละก้อนแบ่งตามตาราง 5.2 ของเส้นทางนั้น เช่น แก่นแท้ 5 เส้นทางที่ได้ 384,000 แต้ม จะแบ่งเป็น 5 ก้อน ก้อนละ 76,800 แต้ม (แก่นแท้ 1 เส้นทางใช้ตารางของเส้นทางนั้นตามปกติ)

**ค่าสเตตัสที่ไม่ได้มาจากการแบ่งแต้มของเส้นทาง**
*   **LUK:** เพิ่มหรือลดได้จากความสามารถบางประเภทเท่านั้น
*   **FAI:** เพิ่มหรือลดได้ตามจำนวนและระดับของผู้ศรัทธาเท่านั้น
*   **CHA:** ได้รับจากการสร้างความสัมพันธ์กับ NPC ให้ถึงระดับที่กำหนดเท่านั้น (ต้องมีระดับตัวตนตั้งแต่ Tier 1 ขึ้นไป)

**หลักการของตาราง 5.2**
- ทุกเส้นทางมีค่าพื้นฐานครบทั้ง 5 ค่า (STR, CON, AGI, INT, PER) และมีค่าพิเศษครบตามตาราง 5.1
- **HAN/BEA** นับเป็นช่องเดียว ใช้ HAN หรือ BEA ตามเพศปัจจุบันของผู้ใช้ ถ้าถูกเปลี่ยนเพศจะแปลงแบบ 1:1 ตามข้อ 4 (ตารางเขียน BEA/HAN ไว้ก่อนสำหรับเส้นทางที่บังคับเปลี่ยนเป็นหญิง ได้แก่ Demoness, Moon, Mother, Chaos Primogenitor)
- เส้นทางที่ใช้เวทธาตุเป็นหลัก (Tyrant, Red Priest, Sun, Door, Condenser) ได้ INT สูงขึ้น เพราะความเสียหายธาตุคำนวณจาก INT × ค่าคงที่ของธาตุ (ข้อ 1.1)
