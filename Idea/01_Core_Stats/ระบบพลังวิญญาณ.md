# ระบบพลังวิญญาณ (Spirituality System)

**พลังวิญญาณ (Spirituality)** คือทรัพยากรหลักที่ใช้ขับเคลื่อนพลังเหนือธรรมชาติ ร่ายเวทมนตร์ และประกอบพิธีกรรม พลังนี้ไหลเวียนอยู่ใน "วิญญาณดารา (Astral Projection)"

---

## 1. มาตรฐานค่าพลังวิญญาณสูงสุด (Max Spirituality)
ค่ามาตรฐานของพลังวิญญาณจะเพิ่มขึ้นตามลำดับขั้นของผู้วิเศษ อย่างไรก็ตาม **ระดับการย่อยโอสถ (Digestion)** จะส่งผลต่อขีดจำกัดพลังงานที่เข้าถึงได้:

*   **กฎการย่อยโอสถ:**
    *   เมื่อการย่อยอยู่ที่ **0%**: ค่า Max Spirituality จะ **ลดลง 30%** จากค่าสูงสุดของลำดับนั้น
    *   เมื่อการย่อยอยู่ที่ **100%**: ค่า Max Spirituality จะกลับเข้าสู่สภาวะปกติสมบูรณ์
    *   *สูตรคำนวณ:* `Max Spirituality = Base Max (ตามลำดับ) x [0.7 + (0.3 x Digestion%)]`

## 2. ตัวคูณประจำเส้นทาง (Pathway Modifiers)
ผู้วิเศษในแต่ละเส้นทางมีความหนาแน่นของพลังวิญญาณแตกต่างกัน โดยค่า Final Max จะนำค่า Base ไปคูณกับตัวคูณประจำเส้นทางดังนี้:

| ตัวคูณ (Modifier) | รายชื่อเส้นทาง (Pathways) |
| :--- | :--- |
| **x1.5 (High)** | Fool, Door, Error, Visionary, Hermit, White Tower, Moon, Mother, Chained, Abyss, Eternal Aeon, Chaos Primogenitor, Patriarch, Chaos Mist, Tail-Devourer, Everlasting, Sublunary Eye, Eternal Edict |
| **x1.2 (Mid)** | Hanged Man, Darkness, Death, Demoness, Inextinguishable Ravings, Uncertain Mist, High-Dimensional Overseer |
| **x1.0 (Balanced)** | Paragon, Justiciar, Black Emperor, Second Law, Monarch of Decay, Supernova Dominator |
| **x0.8 (Low)** | Warrior, Red Priest, Tyrant, Twilight Giant, Primordial Hunger |

## 3. ระบบฟื้นฟูพลังวิญญาณ (Regeneration System)
การฟื้นฟูพลังวิญญาณจะคำนวณเป็น **"ค่าตายตัวต่อวินาที" (Fixed Value per Second)** โดยแปรผันตามลำดับผู้วิเศษ, ระดับกายจิต และสภาวะของผู้เล่น

### **3.1 การฟื้นฟูพื้นฐานตามลำดับ (Base Sequence Regen)**
| ลำดับ (Sequence) | อัตราฟื้นฟูพื้นฐาน (หน่วย/วินาที) |
| :--- | :---: |
| ลำดับ 9 | 1.25 |
| ลำดับ 8 | 2.5 |
| ลำดับ 7 (สาย B) | 5 |
| ลำดับ 7 (สาย A) | 12.5 |

| ลำดับ 3 (นักบุญ) | 500 |

### **3.2 ตัวคูณจากความแข็งแกร่งของกายจิต (Spirit Body Multipliers)**
ความแข็งแกร่งของกายจิต (Tier) จะทำหน้าที่เป็นตัวคูณเพิ่มประสิทธิภาพการฟื้นฟู:
*   **Tier 1 (ผู้วิเศษระดับต่ำ):** x1.0
*   **Tier 2 (ผู้วิเศษระดับกลาง):** x1.5
*   **Tier 3 (นักบุญ):** x2.0
*   **Tier 4 (เทวทูต):** x2.5
*   **Tier 5 (เทพแท้จริง):** x5.0
*   **Tier 6 (วันวาน):** x10.0

### **3.3 รูปแบบการฟื้นฟูในเกมเพลย์**
*   **การฟื้นฟูตามธรรมชาติ (Passive):** `Regen = Base Sequence Regen x Spirit Body Multiplier`
*   **การทำสมาธิ (Cogitation):** ฟื้นฟูแบบก้าวกระโดดโดยการใช้ตัวคูณ **x5** เพิ่มเติมจากค่า Passive
    *   *สูตร:* `Regen (Meditation) = (Base x Spirit Body Tier) x 5`
    *   *ตัวอย่าง:* ผู้วิเศษลำดับ 5 (Base 50) ที่มีระดับกายจิต Tier 2 (x1.5) เมื่อทำสมาธิจะฟื้นฟู: `(50 x 1.5) x 5 = 375 หน่วย/วินาที`
*   **การนอนหลับ:** ฟื้นฟูเต็ม 100% ทันทีเมื่อตื่นนอน
*   **ไอเทม Consumables:** ฟื้นฟูแบบ Burst Heal หรือมอบบัฟเร่งความเร็วตามที่ระบุในไอเทม

## 4. รูปแบบการใช้จ่ายพลังวิญญาณ (Spirituality Consumption)
1.  **Burst Cost:** หักค่าพลังงานคงที่ทันที (เช่น ยิงกระสุนลม)
2.  **Drain Cost:** หักพลังงานต่อเนื่องทุกวินาที (เช่น เปิดเนตรวิญญาณ)
3.  **Ritual Cost:** ใช้พลังงานก้อนใหญ่สำหรับการประกอบพิธีกรรม

---

## 5. สภาวะอ่อนล้าทางวิญญาณ (Spiritual Exhaustion)
หากพลังวิญญาณเหลือ 0% - 5%:
*   **ติด Debuffs:** Nausea, Slowness, Mining Fatigue
*   **ระงับพลัง:** ไม่สามารถใช้ทักษะผู้วิเศษได้จนกว่าจะฟื้นฟูถึง 10%
*   **ความเสี่ยงต่อความคุ้มคลั่ง:** อัตราการลดลงของ Sanity จากปัจจัยภายนอกจะ **รุนแรงขึ้น 2 ท่า** (เนื่องจากวิญญาณดาราอ่อนแอ)
