ลำดับ 7 โหราจารย์ (Astrologer)
ความสามารถใหม่
  - ได้รับเนตรวิญญาณระดับปานกลาง
  - ได้รับความสามารถในการทำนายและทำพิธีกรรม

ความสามารถที่ถูกเสริมแกร่ง
  - กลโจมตี
    - Mode ​ไฟฟ้าช็อต (Electric Shock) จะสามารถสร้างกระแสไฟฟ้าขึ้นมาเคลือบอาวุธหรืออุปกรณ์ได้แล้ว และจะทำให้อาวุธหรืออุปกรณ์ชิ้นนั้นได้รับ dmg เพิ่มเติม 3 dmg
    - Mode การแช่แข็ง (Freezing) เพิ่มรัศมีการแผ่ไอเย็นเป็น 15 block
    - Mode การเผาไหม้ (Burning) เพิ่มระยะการจุดไฟเป็น 10 block และในลำดับนี้สามารถใช้เพื่อทำให้อาหารสุกได้แล้วโดยจะต้องให้อาหารมาอยู่ในมือซ้ายและกดใช้ความสามารถจะเป็นการทำให้อาหารสุก (สามารถให้สุกพร้อมกันได้สูงสุด 16 ชิ้น)
    - Mode ​สายลม (Wind) เพิ่มระยะการพัดเป็น 15 block 
  - กลป้องกัน เป็นความสามารถประเภท Active และมี 4 Mode ดังนี้: 
    - Mode หลบหนี (Escape) เพิ่มจำนวนการเก็บเป็น 7 อัน และเพิ่มระยะ teleport เป็น 15 block
    - ​Mode หกล้ม (Tumble) เพิ่มรัศมีเป็น 10 block
    - Mode แสงแฟลช (Flash) เพิ่มรัศมีเป็น 7 block
    - Mode เสียงดังกึกก้อง (Loud Noise) เพิ่มรัศมีเป็น 7 block
  - กลสนับสนุน เป็นความสามารถประเภท Active และมี 4 Mode ดังนี้:
    - Mode เคลื่อนย้ายก๊าซ (Gas Transfer) เพิ่มรัศมีการควบคุมก็าซรอบตัวผู้ใช้เป็น 7 block และเพิ่มระยะการเคลื่อนย้ายเป็น 20 block 
    - Mode ​การควบคุมวัตถุ (Object Manipulation) เพิ่มระยะเป็น 7 block และในลำดับนี้จะสามารถเคลื่อนย้ายไอเทมได้หลายชิ้นพร้อมกันสูงสุด 5 ชิ้น โดยที่จะเป็นการเมื่อกดใช้งานและเล็งไปยังไอเทมนั้นไอเทมรอบๆไอเทมนั้นในรัศมี 3 block จะถูกเคลื่อนย้ายมาด้วย 
    - Mode ม่านสีดำ (Black Curtain) ในลำดับนี้สามารถสร้างม่านสีดำปกปิดสิ่งมีชึวิตได้แล้ว โดยทีให้ทำการเล็งไปที่สิ่งมีชีวิตตัวนั้นในระยะ 15 block แล้วกดใช้งานความสามารถ และถ้าอยากปกปิดตัวเองจะต้องกด shift + กดใช้งานความสามารถ จะเป็นการปกปิดตัวเอง และเพิ่มระยะเวลาในการปกปิดจะเพิ่มเป็น 30 วินาที และสามารถยกเลิกได้ทุกเมื่อ
    - Mode หมอก (Fog) เพิ่มรัศมีของหมอกเป็น 20 block
  - เปิดประตู (Door Opening)
    - ประตูมายา เพิ่มระยะการพาผู้ใช้ทะลุผ่าน block ไปได้สูงสุดเป็น 27 block และประตูมายาสามารถพาผู้อื่นไปได้แล้ว
