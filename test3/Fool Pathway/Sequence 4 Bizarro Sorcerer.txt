ลำดับ 4 จอมเวทพิสดาร (Bizarro Sorcerer)
ความสามารถใหม่
  - การส่งมอบ (Bestowal) เป็นความสามารถประเภท Passive/Active การทำงานแบบ Active คือ เมื่อกดใช้จะขึ้นหน้า ui ที่จะแสดงหุ่นเชิดทั้งหมดของผู้ใช้ขี้นมา และผู้ใช้สามารถมอบและริบคืน หนอนวิญญาณให้กับหุ่นเชิดได้ โดยที่จะสามารถมอบหนอนวิญญาณให้ได้สูงสุด 50 (ย่อย 0%) - 100 (ย่อย 100%) ตัว และไม่มีข้อจำกัดว่าหุ่นเชิด 1 ตัวจะสามารถมีหนอนวิญญาณได้เท่าไร่ และในแบบ Passive จะทำงานเมื่อ มีการสร้างหุ่นเชิดใหม่ จะทำการมอบหนอนวิญญาณให้แบบอัตโนมัติ แต่จะมอบให้กับแค่หุ่นเชิดที่เกิดจากความสามารถของผู้ใช้เท่านั้น จะไม่มอบให้กับหุ่นเชิดที่เกิดจากความสามารถของตัวหุ่นเชิดอีกที และในแบบ Passive/Active จะไม่มี Cooldown และ ไม่สูญเสียพลังวิญญาณ และเมื่อหุ่นเชิดที่มีหนอนวิญญาณอยู่ถูกทำลายหรือตายไปหนอนวิญญาณในตัวมันจะค่อยๆคลานมาหาตัวผู้ใช้หรือหุ่นเชิดของผู้ใช้ที่อยู่ใกล้ที่สุดเอง (ความเร็วในการเคลื่อนที่ของหนอนวิญญาณจะเท่ากับความเร็วในการวิ่งของมนุษย์ปกติ) และหากในระหว่างที่หนอนวิญญาณกำลังจะกลับเข้าร่างของผู้ใช้หรือหุ่นเชิดของผู้ใช้ถูกสังหารหรือขัดขวางจนทำให้สูญเสียหนอนวิญญาณไปจะสร้างความเสียหายให้กับผู้ใช้
  - การซ่อนเร้น (Concealment) เป็นความสามารถประเภท Passive การทำงานคือ จะทำการปกปิดข้อมูลของผู้ใช้ประมาณ 75% ต่อผู้วิเศษในลำดับเดียวกันหรือต่ำกว่า 

ร่างสัตว์ในตำนาน (Mythical Creature Form)
  - เป็นความสามารถประเภท Active
  - อยู่ในระดับ ร่างสัตว์ในตำนานที่ไม่สมบูรณ์ (Incomplete Mythical Creature Form) เมื่ออยู่ในร่างนี้จะสูญเสียค่าสติ 0.5% ทุกๆ 1 วินาที
  - รูปร่างของร่างสัตว์ในตำนานที่ไม่สมบูรณ์จะมีลักษณะเป็น หนอนวิญญาณ (Worms of Spirit) จำนวน 100 (ย่อย 0%) - 150 (ย่อย 100%) ตัว (ถ้าในจำนวนนี้ถูกนำไปมอบให้กับหุ่นเชิดจำนวนที่จะแสดงออกมาก็จะลดลงไปด้วย) ที่กระจายอยู่รอบๆจุดที่กลายร่าง โดยที่จิตสำนึกของผู้ใช้จะอยู่ในหนอนวิญญาณตัวใดตัวหนึ่งในนั้น และเมื่อหนอนวิญญาณที่มีจิตสำนึกของผู้ใช้อยู่ตายไปจิตสำนึกจะถูกถ่ายโอนไปยังหนอนวิญญาณตัวอื่นที่ยังไม่ตาย และหนอนวิญญาณแต่ละตัวจะมีเลือดอยู่ที่ 100 หน่วย (เลือดของผู้ใช้กับหนอนวิญญาณที่มีจิตสำนึกของผู้ใช้อยู่จะไม่ใช่หลอดเลือดของผู้ใช้ [ในกรณีที่ผู้ใช้อยู่ในร่างสัตว์ในตำนานผู้ใช้จะเห็นทั้งเลือดของตัวเองกับของหนอนวิญญาณตัวที่มีจิตสำนึกของผู้ใช้อยู่]) และเมื่อหนอนวิญญาณตายจะดรอปซากของมันและจะทำให้ผู้ใช้เสียเลือด + เสียค่าสติไปด้วยจำนวนหนึ่งรวมถึงในกรณีที่โดยตัดการเชื่อมต่อกับหนอนวิญญาณไปด้วย โดยที่ในลำดับนี้ถ้าหากผู้ใช้สูญเสียหนอนวิญญาณไปประมาณ 60% ของจำนวนสูงสุดจะทำให้คลุ้มคลั่งทันที และในร่างนี้ผู้ใช้ในร่างของหนอนวิญญาณสามารถโจมตีเป้าหมายได้ และเมื่อโจมตีไปแล้วหนอนวิญญาณรอบๆก็จะมาตีเป้าหมายนั้นด้วย โดยที่โจมตีนั้นจะสร้างความเสียหายประเภทวิญญาณ+กายภาพ และสร้างความเสียหายเท่ากับ ค่า str*1.2 และในร่างนี้ผู้ใช้สามารถใช้ความสามารถต่างๆได้ตามปกติ 
  - ผู้ใช้สามารถนำหนอนวิญญาณออกมาได้โดยในหน้าต่าง Beyonder Journal จะมีปุ่มหรือคำสั่งให้ผู้ใช้สามารถแบ่งหนอนวิญญาณจากร่างกายออกมาได้ ซึ่งจะมาในลักษณะของไอเทม หนอนวิญญาณ ที่สามารถวางมันแล้วจะกลายเป็นม็อบหนอนวิญญาณได้ (สามารถ stack ได้สูงสุด 64 อัน) และผู้ใช้สามารถสังหารหนอนวิญญาณที่ตัวผู้ใช้แบ่งออกมาได้โดยการกด shift + คลิกขวา จะเป็นการสังหารหนอนวิญญาณในมือ เมื่อสังหารเสร็จจะดรอป ซากของหนอนวิญญาณมาให้ผู้ใช้ และเมื่อผู้ใช้สูญเสียหนอนวิญญาณไปจะสามารถฟื้นฟูจำนวนของหนอนวิญญาณให้กลับมาเต็มได้ โดยจะใช้เวลาอยู่ที่ 30 วินาทีต่อตัวและใช้พลังวิญญาณอยู่ที่ 1,000 หน่วยต่อตัว

ความสามารถที่ถูกเสริมแกร่ง
  - การควบคุมด้ายวิญญาณ (Spirit Body Threads Manipulation) เพื่ม Mode ใหม่ 1 Mode จนตอนนี้มี 2 Mode (ทั้ง 2 mode ยังมีข้อจำกัดในการเปลี่ยนเป็นหุ่นเชิดเหมือนเดิม) คือ:
    - Mode ควบคุมด้ายวิญญาณเป้าหมายเดี่ยว (Mode เดิม) เพิ่มระยะการควบคุมด้ายวิญญาณเป็น 150 (ย่อย 0%) - 300 (ย่อย 100%) block และระยะเวลาในการเปลี่ยนเป็นหุ่นเชิดจะอยู่ที่ 15 วินาที
    - Mode ควบคุมด้ายวิญญาณหลายเป้าหมาย (Mode ใหม่) Mode จะทำงานเหมือน Mode เดิม แต่ต่างตรงที่เมื่อกดใช้จะควบคุมด้ายวิญญาณของทุกสิ่งมีชีวิตทั้งหมดเป็นจำนวน 25 ตัวในระยะของการควบคุมด้ายวิญญาณ แล้วการใช้พลังวิญญาณจะเป็นดังนี้ จำนวนที่เข้าควบคุม * 100 หน่วยต่อวินาที (สามารถตั้งค่าสิ่งมีชีวิตที่จะเข้าควบคุมได้ผ่านหน้าต่างความสามารถ) และระยะเวลาในการเปลี่ยนเป็นหุ่นเชิดจะเท่ากับ Mode ควบคุมด้ายวิญญาณเป้าหมายเดี่ยว
  - การควบคุมหุ่นเชิด (Marionette Controlling) เพิ่มจำนวนของหุ่นเชิดเป็น 50 (ย่อย 0%) - 100 (ย่อย 100%) ตัว และเพิ่มระยะการควบคุมหุ่นเชิดเป็น 1,000 block และเพิ่ม Mode ใหม่อีก 1 Mode ดังนี้:
    - Mode ควบคุมทั้งหมด (Mode เดิม) คำสั่งโจมตีเมื่อผู้ใช้ใช้ความสามารถประเภทโจมตีของตัวผู้ใช่หุ่นเชิดที่อยู่ในคำสั่งนี้จะใช้ความสามารถประเภทโจมตีเดียวกับผู้ใช้ แต่หุ่นเชิดตัวนั้นจะต้องมีหนอนวิญญาณอยู่ในตัวด้วย และในคำสั่งอื่นก็จะให้ผลแบบเดียวกันกับคำสั่งโจมตี และเพิ่มคำสั่งใหม่คือคำสั่ง ใช้ด้ายวิญญาณ เมื่อใช้คำสั่งแล้วหุ่นเชิดจะใช้ความสามารถควบคุมด้ายวิญญาณกับเป้าหมายใกล้เคียง โดยที่หุ่นเชิดที่ได้จากคำสั่งนี้จะมาอยู่ในการควบคุมของผู้ใช้ ดังนั้นหากจำนวนหุ่นเชิดของผู้ใช้เต็มจำนวนแล้ว จะไม่สามารถเพิ่มได้อีกแล้ว (หากหุ่นเชิดใช้ความสามารถควบคุมด้ายวิญญาณ ระยะของความสามารถนี้ที่หุ่นเชิดใช้จะต้องอยู่ในระยะของการควบคุมหุ่นเชิดของผู้ใช้เท่านั้น)
    - Mode ควบคุมรายตัว (Mode เดิม) ในกรณีเข้าไปในร่างของหุ่นเชิดที่มีหนอนวิญญาณอยู่ ร่างนั้นจะมีความสามารถของผู้ใช้ทุกอย่างอยู่ให้เลือกใช้ด้วยในหน้าต่างเลือกความสามารถของหุ่นเชิดตัวนั้น
    - Mode สลับตำแหน่ง (Mode ใหม่) เป็นความสามารถประเภท Passive/Active การทำงานคือ เมื่อกดใช้ความสามารถจะทำการสลับตำแหน่งกับหุ่นเชิดที่มีหนอนวิญญาณที่ใกล้ที่สุด แต่หากกด shift + ปุ่มความสามารถ จะสลับตำแหน่งกับหุ่นเชิดที่มีหนอนวิญญาณที่ไกลที่สุดแทน และในหน้าเลือกความสามารถ ความสามารถนี้จะมีให้กด เปิด/ปิด ความสามารถแบบ Passive อยู่ ถ้าเปิดจะแสดงผลคือ เมื่อได้รับความเสียหายประมาณ 5% จะทำการสลับตำแหน่งกับหุ่นเชิดที่มีหนอนวิญญาณที่ไกลที่สุดทันที แต่ถ้าปิดความสามารถแบบ Passive นี้จะไม่ทำงาน และ Cooldown ของการสลับตำแหน่งของทั้งแบบ Passive/Active อยู่ที่ 0.5 (ย่อย 0%) - 1 (ย่อย 0%) วินาที และใช้พลังวิญญาณของทั้งแบบ Passive/Active อยู่ที่ 1,000 หน่วยต่อครั้ง
  - การแปลงโฉม (Shapeshifting) 
    - Passive จดจำรูปลักษณ์ ในลำดับนี้สามารถบันทึกรูปลักษณ์ของเผ่าพันธุ์อื่นได้แล้ว
    - Mode การเปลี่ยนรูปลักษณ์ ในลำดับนี้สามารถเปลี่ยนรูปลักษณ์เป็นเผ่าพันธุ์อื่นได้แล้ว แต่ในการเปลี่ยนรูปลักษณ์เป็นเผ่าพันธุ์อื่นนั้นจะยังไม่ได้รับโบนัสค่าสเตตัสของเผ่าพันธุ์นั้นมา และในการเปลี่ยนรูปลักษณ์เป็นเพศอื่นจะได้รับโบนัสค่าสเตตัสของเพศนั้นมาแล้ว
    - Mode สร้างรูปลักษณ์ เพิ่มจำนวนรูปลักษณ์ที่สร้างได้เป็น 50 รูปลักษณ์ และในลำดับนี้สามารถสร้างรูปลักษณ์เป็นเพศอื่นได้แล้วแต่ยังไม่สามารถสร้างเป็นเผ่าพันธุ์อื่นได้
  - กระสุนอากาศ (Air Bullet) ถูกพัฒนาเป็น ปืนใหญ่อากาศ (Air Cannon) เป็นความสามารถประเภท Active การทำงานจะเหมือนกับ กระสุนอากาศ ทุกประการ แต่จะเพิ่มความเสียหายเป็น 50 (ย่อย 0%) - 70 (ย่อย 100%) dmg และระยะเพิ่มเป็น 200 (ย่อย 0%) - 300 (ย่อย 100%) block และขนาดของกระสุนจะมีขนาดเท่ากับ 1 block และเมื่อกระทบกับสภาพแวดล้อมจะทำลายบริเวณนั้นด้วย โดยการทำลายจะเทียบเท่ากับ tnt ครึ่งลูก และใช้พลังวิญญาณอยู่ที่ 500 หน่วยต่อครั้ง และความสามารถนี้ถ้าโดนเป้าหมายจะสร้างความเสียหายประเภท กายภาพ (80%) + วิญญาณ (20%) รวมด้วย
  - การหายใจใต้น้ำ (Underwater Breathing) เพิ่มความลึกเป็น 50 block
  - การควบคุมเปลวไฟ (Flame Controlling)
    - Mode จุดชนวนไฟ เพิ่มระยะการจุดไฟเป็น 1,000 block 
    - Mode กระโดดไฟ เพิ่มระยะการกระโดดไฟเป็น 1,000 block
    - Mode ควบคุมเปลวไฟ เพิ่มระยะการควบคุมไฟเป็น 500 block และจำนวนสูงสุดของไฟลูกคือ 50 ลูก และความเสียหายเพิ่มเป็น 30 dmg และความสามารถนี้ถ้าโดนเป้าหมายจะสร้างความเสียหายประเภท กายภาพ (60%) + วิญญาณ (40%) รวมด้วย
  - การสร้างภาพลวงตา (Illusion Creation)
    - Mode สร้างภาพลวงตากับสิ่งแวดล้อม เพิ่มจำนวนภาพลวงตาที่สร้างเป็น 200 block และสามารถสร้างภาพลวงตาแบบสำเร็จรูปได้แล้ว เช่น ภาพลวงตาของบ้านทั้งหลัง, ภาพลวงตาของสิ่งก่อสร้างทั้งอัน เป็นต้น แต่ภาพลวงตาสำเร็จรูปนี้จะมีระยะเท่ากับจำนวน block ของภาพลวงตาในลำดับนั้น เช่น หากสร้างภาพลวงตาของ mineshaft ภาพลวงตานั้นจะมีระยะไม่เกินจำนวน block ลวงตาที่สร้างได้เท่านั้นซึ่งในระยะนี้จะมีจำนวน block ลวงตาเท่ากับ 200 block เท่านั้น เป็นต้น แต่ยังจำกัดหมวดหมู่แค่สิ่งก่อสร้างเท่านั้น และสามารถสร้าง block ลวงตาประเภทของไหลได้แล้ว
