# ปรับแก้ระบบค่าสเตตัส
---
## 1. ค่าสเตตัสต่างๆ

### 1.1 ค่าสเตตัสพื้นฐาน
ค่าสเตตัสพื้นฐานคือค่าสเตตัสที่ทุกสิ่งมีชีวิตมีเหมือนกัน (ค่าสเตตัสพื้นฐานจะเริ่มต้นที่ 10 แต้ม)
*   **พละกำลัง (Strength - STR)** 
    * เพิ่มความเสียหาย Melee และระยะ Knockback เมื่อโจมตีปกติ
    * ส่งผลต่อความรุนแรงของทักษะสายกายภาพ (ในกรณีที่มีการนำค่า STR ไปคำนวณความเสียหายเท่านั้น)
    * เพิ่มความสูงของการกระโดด
*   **ความทนทาน (Constitution - CON):**
    * เพิ่ม Max HP
    * ส่งผลให้ได้รับ "ค่าเกราะกายภาพ" โดยตรง
    * ช่วยลดระยะจากการโดน Knockback
    * มีผลต่อ Spiritual Armor (ร่วมกับ INT และ INS)
*   **ความคล่องตัว (Agility - AGI):**
    * เพิ่มความเร็วในการเคลื่อนที่
    * เพิ่มความเร็วโจมตี
    * ลดความเสียหายจากการตกจากที่สูง
    * มีผลต่อ Normal Evasion (ร่วมกับ PER)
*   **สติปัญญา (Intelligence - INT):**
    * ปลดล็อก "การป้องกันทางจิต"
    * มีผลต่อ Spiritual Armor (ร่วมกับ INS และ CON)
    * ส่งผลต่อความรุนแรงของทักษะสายจิตใจหรือวิญญาณ (ในกรณีที่มีการนำค่า INT ไปคำนวณความเสียหายเท่านั้น)
*   **ประสาทสัมผัส (Perception - PER):**
    * ช่วยให้สัมผัสถึงแรงดึงดูดของตะกอนพลัง ทำให้รู้ตัวเมื่อมีผู้วิเศษหรือสมบัติระดับสูงอยู่ใกล้ๆผุ้ใช้ โดยที่มันจะแสดงออกมาในลักษณะของแสงสีต่างตามระดับของเป้าหมายเมื่อเทียบกับผู้ใช้ จากสีเขียว (ปลอดภัย) ถึง สีแดง (อันตราย) (ความสามารถนี้จะส่งผลต่อเมื่อค่า PER สูงเกินจุดที่กำหนด)
    * มีผลต่อ Normal Evasion (ร่วมกับ AGI)
    * ส่งผลต่อระยะการตรวจจับของ Danger Intuition หรือความสามารถที่มีการนำค่า PER ไปคำนวณ 

### 1.2 ค่าสเตตัสพิเศษ
เป็นค่าสเตตัสที่มีเงื่อนไขในการได้รับ
*   **เสน่ห์ (Charm - CHA)** จะต้องมีระดับตัวตน (ความแข็งแกร่งของกายจิต) ตั้งแต่ Tier 1 ขึ้นไป (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * ลดราคาไอเทมจาก NPC พ่อค้า
    * ลดระยะตรวจจับของม็อบสิ่งมีชีวิตทั่วไป
    * มีโอกาศที่จะได้รับรางวัลตอบแทนจากภารกิจเพิ่มเติม (ความสามารถนี้จะส่งผลต่อเมื่อค่า CHA สูงเกินจุดที่กำหนด)
*   **โชค (Luck - LUK)** จะต้องมีระดับตัวตน (ความแข็งแกร่งของกายจิต) ตั้งแต่ Tier 1 ขึ้นไป (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * ค่า LUK จะมีค่าสูงสุดอยู่ที่ +100 และต่ำสุดอยู่ที่ -100
    * เมื่อค่า LUK สูงเกินจุดที่กำหนด จะทำให้ผู้ใช้ได้ของดีๆเมื่อทำการสุ่มหรือความสามารถที่มีโอกาศทำงานก็จะเพิ่มโอกาศทำงานได้มากขึ้น
    * เมื่อค่า LUK ต่ำเกินจุดที่กำหนด จะทำให้ผู้ใช้ได้ของไม่ดีเมื่อทำการสุ่มหรือความสามารถที่มีโอกาศทำงานก็จะลดโอกาศทำงานมากขึ้น
    * **ค่า LUK จะเพิ่มลดได้จากความสามารถบางประเภทเท่านั้น**
*   **ความงาม (Beauty - BEA):** จะต้องเป็นเพศหญิงเท่านั้น (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มความสัมพันธ์กับ NPC เพศตรงข้ามได้ง่ายขึ้น
    * มีโอกาศที่ NPC หรือม็อบจะไม่โจมตีผู้ใช้เมื่อผู้ใช้โจมตีก่อน (ความสามารถนี้จะส่งผลต่อเมื่อค่า BEA สูงเกินจุดที่กำหนด)
    * มีโอกาศที่ NPC หรือม็อบจะกลายเป็นทาสของผู้ใช้ ทาสมีทั้งแบบชั่วคราวและถาวร โดยที่ในการจะเปลี่ยนเป็นทาสได้นั้นจะคำนวณจากค่า BEA ของผู้ใช้เทียบกับค่า INT ของเป้าหมาย หากค่าที่ได้มันห่างกันมากกว่า 10 เท่า เป้าหมายจะถูกเปลี่ยนเป็นทาสชั่วคราว และหากมากกว่า 50 เท่า จะถูกเปลี่ยนเป็นทาสถาวร (ความสามารถนี้จะส่งผลต่อเมื่อค่า BEA สูงเกินจุดที่กำหนด)
*   **ความหล่อ (Handsome - HAN):** จะต้องเป็นเพศชายเท่านั้น (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มความสัมพันธ์กับ NPC เพศตรงข้ามได้ง่ายขึ้น
    * มีโอกาศที่ NPC หรือม็อบจะไม่โจมตีผู้ใช้เมื่อผู้ใช้โจมตีก่อน (ความสามารถนี้จะส่งผลต่อเมื่อค่า HAN สูงเกินจุดที่กำหนด)
    * สามารถชวน NPC มาเป็นพวกได้โดยที่ไม่ต้องให้มีค่าความสัมพันธ์ถึงเกณฑ์ และพวกพ้องของผู้ใช้จะได้รับโบนัสค่าสเตตัสตั้งแต่ x1.1 ถึง x2 ตามค่า HAN ของผู้ใช้ และโบนัสเพิ่มประสิทธิภาพของความสามารถตั้งแต่ x1.1 ถึง x3 ตามค่า HAN ของผู้ใช้ (ความสามารถนี้จะส่งผลต่อเมื่อค่า HAN สูงเกินจุดที่กำหนด)
*   **บารมี (Presence - PRE):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มค่าความเชื่อใจ (Trust) ของ NPC กับผู้ใช้ได้ง่ายขึ้น
    * เพิ่มประสิทธิภาพของจุดยึดเหนี่ยว (Anchors) ทำให้การเปลี่ยน NPC เป็นผู้ศรัทธาทำได้ง่ายขึ้น
    * มีโอกาศที่สิ่งมีชีวิตจะไม่โจมตีผู้ใช้ (ความสามารถนี้จะส่งผลต่อเมื่อค่า PRE สูงเกินจุดที่กำหนด)
*   **อำนาจข่มขู่ (Dominance - DOM):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * ส่งผลต่อความรุนแรงของบางความสามารถที่ใช้ค่า DOM ไปคำนวณ
    * มีโอกาศที่จะสามารถบังคับให้ NPC มาเป็นพวกเดียวกับผู้ใช้ได้ แต่ค่าสเตตัสของเป้าหมายที่โดนบังคับมาจะลดลงตั้งแต่ -10% ถึง -50% ตามค่า DOM ของผู้ใช้ และพวกพ้องที่โดนบังคับมาจะมีระยะเวลาในการอยู่ในทีมตั้งแต่ 1 วันในเกม ถึง 100 วันในเกม ตามค่า DOM ของผู้ใช้ (ความสามารถนี้จะส่งผลต่อเมื่อค่า DOM สูงเกินจุดที่กำหนด)
*   **ปัญญาญาณ (Insight - INS):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มประสิทธิภาพของทักษะสาย การทำนาย (Divination), การพยากรณ์ (Prophecy) และ การมองเห็นอนาคต (Foresight)
    * ส่งผลต่อ Spiritual Armor (ร่วมกับ INT และ CON)
    * เมื่อค่า INS สูงเกินจุดที่กำหนด: ผู้ใช้จะสามารถ เห็นผ่านภาพลวงตา (Illusion Piercing) และ ตรวจจับศัตรูที่ใช้การล่องหนหรือซ่อนตัว ได้ (ตอบโต้สกิล Concealment)
    * ส่งผลต่อความรุนแรงของทักษะที่มีการนำค่า INS ไปคำนวณ
*   **ความทนทุกข์ (Fortitude - FOR):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มค่า ต้านทานสถานะผิดปกติ (Status Resistance) ทุกชนิด เช่น สลบ, หลับ, หลอน, ถูกสาป, ถูกสะกดจิต, ถูกบังคับ ฯลฯ
    * ลดระยะเวลาของ Debuff ที่ผู้ใช้ได้รับ
    * เมื่อค่า FOR สูงเกินจุดที่กำหนด: ผู้ใช้จะมีโอกาศที่จะ ภูมิคุ้มกันสมบูรณ์ (Full Immunity) ต่อ Status Effect ที่มีระดับต่ำกว่าจุดที่กำหนด
    * มีผลต่อ การป้องกันทางจิต (ร่วมกับ INT)
*   **ศรัทธา (Faith - FAI):** เงื่อนไข: จะได้รับเมื่อถึงครึ่งเทพเท่านั้น (เริ่มต้นที่ 0 แต้ม) และค่านี้จะ เพิ่มลดได้ตามจำนวนและระดับของผู้ศรัทธา (Believers) ที่ผู้ใช้ครอบครอง
    * เพิ่มประสิทธิภาพของ จุดยึดเหนี่ยว (Anchors) ทำให้ต้านทานการสูญเสียตัวตนได้ดีขึ้น
    * เมื่อค่า FAI สูงเกินจุดที่กำหนด: ผู้ใช้จะสามารถ ประทานพร (Bestow Blessings) ให้ผู้ศรัทธาของตนได้ ผู้ศรัทธาจะได้รับโบนัสค่าสเตตัสตั้งแต่ x1.05 ถึง x1.5 ตามค่า FAI ของผู้ใช้
    * ค่า FAI จะเพิ่มลดได้จากจำนวนและระดับของผู้ศรัทธาเท่านั้น (คล้ายกับค่า LUK ที่เพิ่มลดได้จากความสามารถบางประเภท)
*   **เล่ห์เหลี่ยม (Cunning - CUN):** จะได้รับจากบางเส้นทาง (ค่าสเตตัสนี้จะเริ่มต้นที่ 0 แต้ม)
    * เพิ่มประสิทธิภาพของทักษะสาย Stealth, Disguise, Theft, Deception
    * ลดระยะตรวจจับของม็อบระดับ Boss/Named NPC (ม็อบที่ปกติมองผ่านการซ่อนตัวได้)

## 3. การเพิ่มลดของค่าสเตตัส

### 3.1 จากการดื่มโอสถ
การดื่มโอสถแต่ละลำดับจะช่วยเพิ่มค่าสเตตัสแบบคงที่ตามในข้อ 2.1 แต่หากดื่มโอสถในลำดับเดียวกับที่เคยดื่มไปแล้วค่าสเตตัสที่ได้รับก็จะลดลงตามนี้
*   **ซ้ำอันแรก:** ได้รับค่าสเตตัสลดลง **-75%**
*   **ซ้ำอันที่สอง:** ได้รับค่าสเตตัสลดลง **-95%**
*   **ซ้ำอันที่สามขึ้นไป:** ได้รับค่าสเตตัสลดลง **-100%** (ไม่ได้รับค่าสเตตัสเพิ่มอีกต่อไป)

### 3.2 โบนัสเพิ่มค่าสเตตัสจากระดับตัวตน
ในแต่ละระดับตัวตนจะได้รับโบนัสค่าสเตตัสตามนี้
*  **Tier 0:** ค่าสเตตัสทุกอย่าง x1 ยกเว้น LUK, FAI
*  **Tier 1:** ค่าสเตตัสทุกอย่าง x1.2 ยกเว้น LUK, FAI
*  **Tier 2:** ค่าสเตตัสทุกอย่าง x1.5 ยกเว้น LUK, FAI
*  **Tier 3:** ค่าสเตตัสทุกอย่าง x2 ยกเว้น LUK, FAI
*  **Tier 4:** ค่าสเตตัสทุกอย่าง x4 ยกเว้น LUK, FAI (ลำดับ 1 พิเศษก็อยู่ใน Tier นี้ด้วย)
*  **Tier 5:** ค่าสเตตัสทุกอย่าง x6 ยกเว้น LUK, FAI (ลำดับ 0 พิเศษก็อยู่ใน Tier นี้ด้วย)
*  **Tier 6:** ค่าสเตตัสทุกอย่าง x10 ยกเว้น LUK, FAI

### 3.3 ไอเทมและพิธีกรรมต่างๆ
ไอเทมและพิธีกรรมต่างๆ สามารถช่วยเพิ่มหรือลดค่าสเตตัสได้ แต่ผลของพวกมันจะอยู่เพียงชั่วคราว

## 5. ความถนัดของเส้นทางทั้ง 32 เส้นทาง
ในแต่ละเส้นทางค่าสเตตัสที่เพิ่มขึ้นจะถูกแบ่งออกเป็น 3 ส่วนได้แก่:
*   **สเตตัสหลัก (Primary):** ได้รับส่วนแบ่งประมาณ **60%** ของค่าสเตตัสรวม
*   **สเตตัสรอง (Secondary):** ได้รับส่วนแบ่งประมาณ **25%** ของค่าสเตตัสรวม
*   **สเตตัสอื่นๆ (Tertiary):** ได้รับส่วนแบ่ง **15%** ของค่าสเตตัสรวม
